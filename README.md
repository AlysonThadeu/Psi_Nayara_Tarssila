## 📋 Sobre o Projeto

Landing page moderna e responsiva desenvolvida para divulgação profissional da **Psicóloga Naiara Tassila**, com foco em conversão de clientes através do Instagram e WhatsApp.

### Características

- ✅ **Design Premium** — Paleta terrosa suave com tipografia elegante (Playfair Display + Inter)
- ✅ **Totalmente Responsivo** — Mobile-first, adaptado para todos os dispositivos
- ✅ **Animações Suaves** — Scroll reveal, counters animados, typed text, parallax sutil
- ✅ **SEO Otimizado** — Meta tags, Open Graph, JSON-LD, heading hierarchy
- ✅ **Performance** — Vanilla JS, sem dependências externas, lazy loading
- ✅ **Acessibilidade** — ARIA labels, focus-visible, semântica HTML5
- ✅ **WhatsApp CTA** — Botão flutuante e múltiplos pontos de conversão

## 🚀 Como Executar

### Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/naiara-tassila-psi.git
   ```

2. Abra o `index.html` no navegador, ou use um servidor local:
   ```bash
   # Com Python
   python -m http.server 8000
   
   # Com Node.js (npx)
   npx serve .
   
   # Com VS Code
   # Instale a extensão "Live Server" e clique em "Go Live"
   ```

3. Acesse `http://localhost:8000`

### Deploy na Vercel

1. Faça push do projeto para o GitHub
2. Acesse [vercel.com](https://vercel.com) e importe o repositório
3. O deploy é automático — sem configuração necessária
